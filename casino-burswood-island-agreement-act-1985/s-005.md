### 5. Reserves Nos. 23251 and 19631 at Burswood Island cancelled
(1) Reserve No. 23251 —
(a) which is classified as of Class A, contains about 39.681 0 hectares and is set apart for “Recreation”; and
(b) a portion of which is vested in the City of Perth,
is hereby cancelled.
(2) Reserve No. 19631, which is classified as of Class C, contains about 12.549 0 hectares and is set apart for “Railway Purposes”, is hereby cancelled.
