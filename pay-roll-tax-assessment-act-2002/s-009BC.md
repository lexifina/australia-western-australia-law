### 9BC. Basis for including value of fringe benefits in returns
(1) If an employer is required to specify in a return WA taxable wages that include the value of fringe benefits provided by the employer, the employer may, instead of including the actual value of the fringe benefits, include a value of the fringe benefits calculated using the estimated value method, if the employer is eligible to do so.
(2) An employer must use the same basis upon which to include the value of fringe benefits in returns for all returns for an assessment year unless the Commissioner allows a change during that year under section 9BH(4).
