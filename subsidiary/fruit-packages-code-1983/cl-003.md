### 3. Application
(1) This Code is, subject to subclauses (2) and (3) of this clause, the relevant code under the Agricultural Products Act 1929 specifying packages to be used for the sale of fruit within the State.
(2) This Code does not apply to a retail sale.
(3) This Code does not apply where fruit is sold or intended to be sold for the purpose of manufacturing, processing or packing.
