### 12B. Funds prescribed (Act s. 4A(1) default fund)
For the purposes of the definition of default fund paragraph (a), in section 4A(1) of the Act, the default fund for an employee is —
(a) if the employee is a West State Super Member — the West State Super Scheme;
(b) in any other case — the GESB Super Scheme.
