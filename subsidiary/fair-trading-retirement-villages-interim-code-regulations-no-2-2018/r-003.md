### 3. Code of Practice prescribed
(1) The code of practice set out in Schedule 1 and cited as the Interim Code of Practice for Retirement Villages (No. 2) 2018 is prescribed under section 46(1) of the Act as an interim code of practice that applies in relation to retirement villages as defined in the Retirement Villages Act 1992 section 3(1).
(2) The Interim Code of Practice for Retirement Villages (No. 2) 2018 has effect for the period of 6 months beginning on 1 October 2018.
