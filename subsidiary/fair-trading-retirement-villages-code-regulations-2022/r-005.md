### 5. Terms used and boxed and shaded paragraphs in code of practice
(1) Except where the contrary intention appears, a term used in the Code of Practice for Retirement Villages 2022 has the same meaning as it has in the Retirement Villages Act 1992.
(2) Boxed and shaded paragraphs in the Code of Practice for Retirement Villages 2022 are not part of the Code and are included only to assist readers of the Code.
