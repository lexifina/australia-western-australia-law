## Division 4 — Miscellaneous
### 2.7. Compliance
(1) A gas marketing agent who contravenes a provision of this Code commits an offence.
Penalty —
(a)for an individual, $5 000;
(b)for a body corporate, $20 000.
(2) If a gas marketing agent of a retailer contravenes a provision of this Code, the retailer commits an offence.
Penalty —
(a)for an individual, $5 000;
(b)for a body corporate, $20 000.
(3) It is a defence to a prosecution for a contravention of subclause (2) if the retailer proves that the retailer used reasonable endeavours to ensure that the gas marketing agent complied with this Code.
