### 3. Application
(1) This Code is, subject to subclauses (2) and (3) of this clause, the relevant code under the Agricultural Products Act 1929 for the grading, marking and packing of pears for sale.
(2) Clauses 10 and 11 of this Code do not apply to a retail sale.
(3) This Code does not apply where pears are sold or intended to be sold for the purpose of manufacturing, processing or packing.
