### 3. Code of Practice prescribed
(1) In this regulation —
client, supplier and fitness service have the meanings given to them in the Code of Practice set out in Schedule 1.
(2) The Code of Practice set out in Schedule 1 and entitled the Fitness Industry Code of Practice 2018 is prescribed under section 46(1) of the Act as an interim code of practice that applies in relation to clients and suppliers of fitness services.
