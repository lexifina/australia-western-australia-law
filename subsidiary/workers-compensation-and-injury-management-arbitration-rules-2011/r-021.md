### 21. Substituted service
(1) If for any reason it is impracticable to serve a document in the manner set out in rule 16, an arbitrator or the Registrar may order that the document may be served by taking such steps as are set out in the order.
(2) An application for an order under this rule must —
(a) be made by the person required to serve the document; and
(b) set out the grounds upon which the application is made; and
(c) be verified by statutory declaration.
(3) A document is to be taken to be served if such steps as are set out in the order are taken.
