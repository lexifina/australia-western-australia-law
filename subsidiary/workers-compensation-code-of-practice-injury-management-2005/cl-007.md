## Part 3 — Return to work programs
### 7. Establishment of a return to work program
(1) The employer has to give a worker who suffers an injury compensable under the Act an opportunity to participate in the establishment of a return to work program for the worker.
(2) The employer has to take reasonable steps to ensure that the worker agrees with the content of the worker’s return to work program.
(3) The return to work program has to be described in writing.
