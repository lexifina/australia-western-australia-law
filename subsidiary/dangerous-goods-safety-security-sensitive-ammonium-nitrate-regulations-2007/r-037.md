### 37. Licences not transferable etc.
(1) A licence is valid only for the person to whom it is issued.
(2) A licence that relates to a place specified in it is valid only for that place.
(3) A licence that relates to an SRS specified in it is valid only for that SRS.
(4) A licence that relates to a maximum quantity of an SRS specified in it is valid only for that quantity.
