### 3. Code of practice prescribed
(1) The code of practice set out in Schedule 1 and cited as the Interim Code of Fair Practice for Retirement Villages 2012 is prescribed under the Fair Trading Act 2010 section 46 as a code of practice that applies in relation to retirement villages as defined in the Retirement Villages Act 1992.
(2) The Interim Code of Fair Practice for Retirement Villages 2012 is to remain in force for the period of 6 months beginning on 1 October 2012.
