### 3. Code of Practice prescribed
(1) In this regulation —
client, fitness service and supplier have the meanings given to them in the Code of Practice set out in Schedule 1.
(2) The Code of Practice set out in Schedule 1 and titled the Fitness Industry Interim Code of Practice 2021 is prescribed under section 46(1) of the Act as an interim code of practice that applies in relation to clients and suppliers of fitness services.
(3) The Fitness Industry Interim Code of Practice 2021 has effect for the period of 6 months beginning on 1 January 2021.
