### 128. Dealing with void matches
(1) If one or more of the matches numbered 1 to 38 on the match list for a Soccer Pools Game are void matches, those matches are to be replaced on the match list, starting with the void match with the lowest number.
(2) If a void match is to be replaced under subrule (1) it is to be replaced with the first match numbered 39 or higher on the match list which —
(a) is not a void match; and
(b) has not already been used as a replacement for another void match.
