### 24. Game processing establishments
(1) The operator of a game processing establishment must comply with the Game Standard.
(2) The operator of a game processing establishment must ensure that carcases of different kinds of game are not processed in the same part of the establishment at the same time.
(3) An operator of a game processing establishment must ensure that the temperature in any part of the establishment where carcases or meat are inspected, branded or processed does not exceed 10°C.
