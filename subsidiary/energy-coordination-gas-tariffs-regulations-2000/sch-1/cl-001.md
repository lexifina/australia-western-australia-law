## Part 1 — Mid-West/South-West area
### 1. Residential tariff
Under this Schedule a charge for the supply of gas for residential purposes is calculated by adding the fixed component and the usage components, each of which is calculated at the rate shown in the Table to this clause or, where applicable, that rate as adjusted under Part 4.
Rates for components of residential tariff
Fixed component | 19.73 cents per day
Usage components
·first usage component | 13.61 cents per unit for the first L units
·second usage component | 12.28 cents per unit for the next M units
·third usage component | 12.28 cents per unit for each additional unit Where — (a)for a single dwelling supplied through a separately metered supply point — L =12 Î N M =24 Î N N =the number of days in the period for which the charge is calculated (b)for multiple dwellings supplied through a commonly metered supply point — L = [12 Î N] + [(F-1) Î 5] M = [24 Î N] + [(F-1) Î 5] N =the number of days in the period for which the charge is calculated F = the number of dwellings
