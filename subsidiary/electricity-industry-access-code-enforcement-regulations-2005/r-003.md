### 3. Terms used in these regulations
In these regulations, unless the contrary intention appears —
civil penalty provision has the meaning given to that term in regulation 4(1);
Code means the Code for the time being in force under section 104 of the Act;
conduct provision means a provision of the Code listed in the Table to Schedule 2 clause 2;
regulatory provision means a provision of the Code listed in the Table to Schedule 2 clause 1.
