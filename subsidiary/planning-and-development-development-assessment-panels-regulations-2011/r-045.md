## Division 4 — Conduct of DAP members
### 45. Code of conduct
(1) The Planning CEO must make and maintain a written code of conduct in respect of DAPs.
(2) Each person performing functions as a DAP member must comply with the code of conduct.
(3) The Planning CEO may amend the code of conduct from time to time.
