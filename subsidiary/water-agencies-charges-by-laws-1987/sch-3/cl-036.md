### 36. Limit on increase
For the purposes of this Division, the maximum charge (“R”) is calculated in accordance with the following formula —
If (P + Q) - A > B, then —
if (A ´ S) > (A + J), then
(A ´ S)
or if (A ´ S) £ (A + J), then
(A + J)
or if (P + Q) - A £ B, then —
if (A ´ S) > [A + {(P + Q) - A} / O], then
(A ´ S)
or if (A ´ S) £ [A + {(P + Q) - A} / O], then
[A + {(P + Q) - A} / O]
where —
P =the target annual charge, based on the number of major fixtures calculated using the Table in item 37;
Q =the ultimate discharge charge calculated using the formula in item 38, except that the discharge allowance calculated in accordance with item 39(a) is 200 kL;
A =the equivalent full year charge payable in the 2005/2006 year;
S =1.136;
B =$500.00;
J =$166.67;
O =3
