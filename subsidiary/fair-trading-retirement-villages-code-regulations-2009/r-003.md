### 3. Code of Practice prescribed
The Code of Practice set out in Schedule 1 and cited as the Code of Fair Practice for Retirement Villages 2009 is prescribed under the Fair Trading Act 2010 Part 4 as a code of practice that applies in relation to retirement villages as defined in the Retirement Villages Act 1992.
