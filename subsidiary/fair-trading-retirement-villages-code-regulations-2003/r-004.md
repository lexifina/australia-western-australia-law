### 4. Interpretation
(1) In the Code set out in Schedule 1 —
“relevant Tribunal” means the Retirement Villages Disputes Tribunal established under section 27 of the Retirement Villages Act 1992, or such other Tribunal that may assume the functions of that Tribunal, whichever is appropriate.
(2) Except where the contrary intention appears, words and expressions used in the Code set out in Schedule 1 have the same meaning as are given to them in the Retirement Villages Act 1992.
(3) Boxed and shaded paragraphs in the Code set out in Schedule 1 are not part of the Code and are included only to assist readers of the Code.
