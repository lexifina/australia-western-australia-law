### 3. Code of Practice prescribed and transitional
(1) The Code of Practice set out in Schedule 1 and cited as the Code of Fair Practice for Retirement Villages 2003 is prescribed under section 43(1) of the Fair Trading Act 1987 as a code of practice that applies in relation to retirement villages as defined in the Retirement Villages Act 1992.
(2) Despite subregulation (1), between 1 October 2003 and 31 December 2003 (inclusive) compliance with the requirements of either —
(a) Division 4 of the Code of Fair Practice for Retirement Villages 2003 prescribed by subregulation (1); or
(b) Division 4 of the Interim Code of Fair Practice for Retirement Villages 2003 prescribed by the Fair Trading (Retirement Villages Interim Code) Regulations 2003,
is prescribed as being sufficient compliance with Division 4 of the Code of Fair Practice for Retirement Villages 2003.
