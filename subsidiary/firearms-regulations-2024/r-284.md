## Division 5 — Shared compliant storage
### 284. Requirements for shared compliant storage (Act s. 311)
For the purposes of section 311(3) of the Act, a person must not store a firearm in shared compliant storage unless —
(a) the firearm is rendered temporarily inoperable, including, for example, by —
(i) using a trigger or action lock; or
(ii) removing a bolt, firing pin or major firearm part from the firearm;
and
(b) if paragraph (a)(i) applies and the lock uses a key or code and the key or code is or will be stored with the firearm — ensure that the key or code is stored in a different firearm repository to the firearm; and
(c) if paragraph (a)(ii) applies and the removed bolt, pin or part is or will be stored with the firearm — ensure that the removed bolt, pin or part is stored in a different firearm repository to the firearm.
Penalty: a fine of $5 000.
