### 4. Compliance with the Code
(1) This Code contains provisions relating to the fitness industry with which a supplier must comply.
(2) Without limiting subclause (1), the supplier must comply with this Code even though a client asks the supplier to do something contrary to this Code.
Note:Contravention of this Code is a ground for —
·seeking an order that the person cease contravening the Code under the Fair Trading Act 2010 section 47;
·seeking an order that the person rectify any consequence of that contravention under the Fair Trading Act 2010 section 47;
·obtaining an injunction under the Fair Trading Act 2010 section 100;
·seeking an order for compensation or another remedial order referred to in the Fair Trading Act 2010 section 105.
[Clause 4 amended in Gazette 30 Jun 2011 p. 2644.]
