### 3. Code of Practice prescribed
(1) In this regulation —
client, supplier and fitness service have the meanings given to them in the Code of Practice in Schedule 1.
(2) The Code of Practice set out in Schedule 1 and entitled the Fitness Industry Code of Practice 2010 prescribed under the Fair Trading Act 1987 section 43(1), continues in force as a code of practice that applies in relation to clients and suppliers of fitness services.
(3) The Fair Trading (Fitness Industry Code of Practice) Regulations 2007 are repealed.
