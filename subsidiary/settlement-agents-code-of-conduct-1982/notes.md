A definition of “prescribed financial market” is deemed to have been inserted into rule 8(3) on 11 March 2002 by Settlement Agents’ Code of Conduct Amendment Rules 2003. On 31 May 2002 rule 8(3) was replaced by a new rule 8(3) which only included a definition of “substantial shareholder”, see Settlement Agents’ Code of Conduct Amendment Rules 2002. The likely result is that rule 8(3) does not include a definition of “prescribed financial market”, and did not on and from 31 May 2002.
