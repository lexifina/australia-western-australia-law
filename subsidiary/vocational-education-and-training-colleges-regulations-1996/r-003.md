### 3. Definitions
(1) In these regulations the expression “category A course”, “category B course”, “category C course” or “category D course” means a course classified as of that category under regulation 4.
(2) In these regulations a reference to the number of hours for a course is a reference to —
(a) for a course that is accredited by the Training Accreditation Council — the number of hours set out in the submission for accreditation made by the course provider to the Training Accreditation Council as being the number of hours in which an average student could reasonably be expected to complete the course; or
(b) for a course in respect of which there is a training package approved by the Minister — the number of hours set out for the course in the training package as being the number of hours in which an average student could reasonably be expected to complete the course.
(3) For the purposes of these regulations “completing a course” —
(a) includes undertaking any assessment required to be undertaken to complete the course; but
(b) does not include undertaking any of the following —
(i) unsupervised work experience;
(ii) unsupervised industry placement;
(iii) unsupervised field placement;
(iv) private study.
