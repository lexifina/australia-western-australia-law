### 151. Affidavit must be filed with response to application in a case
(1) A respondent who files a response to an application in a case must, at the same time, file an affidavit stating the facts relied on in support of the response to an application in a case.
(2) Subrule (1) does not apply to a response to an application in a case filed in response to an application to review an order of a registrar.
