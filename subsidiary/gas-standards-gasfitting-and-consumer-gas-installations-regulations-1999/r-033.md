### 33. Interpretation of codes and standards
(1) If a term is defined both in these regulations and in a code or standard specified in regulation 32(1)(b) the definition in these regulations prevails.
(2) A reference in a code or standard to an “Authority” is to be read as a reference to —
(a) the Director; or
(b) if the Director so approves, an inspector.
(3) In AS 5601/AG 601 — 2002 —
(a) a reference to a “consumer billing meter” is to be read as a reference to a master meter; and
(b) a reference to a “sub-meter” is to be read as a reference to a meter used to measure the amount of gas supplied to a point beyond the master meter.
