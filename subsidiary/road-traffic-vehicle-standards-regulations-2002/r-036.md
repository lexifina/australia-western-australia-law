### 36. What must be included in a class 3 notice or class 3 permit
A class 3 notice or class 3 permit must specify —
(a) the vehicles to which it applies;
(b) the provisions of Part 3 or of the Vehicle Standards from which exemption is given;
(c) the conditions subject to which it is issued;
(d) the period for which it is to remain in force; and
(e) in the case of a class 3 permit —
(i) the name and address of the person to whom it is issued; and
(ii) the registration number of each motor vehicle to which it relates.
