### 27A. Transitional provision for the Settlement Agents Code of Conduct Amendment Rules 2020
(1) In this rule —
commencement day means the day on which the Settlement Agents Code of Conduct Amendment Rules 2020 rule 3 comes into operation.
(2) Rules 23 and 24 of these rules as in force immediately before commencement day continue to apply to cases in which a costs disclosure is given to a client before commencement day.
[Rule 27A inserted: SL 2020/221 r. 6.]
