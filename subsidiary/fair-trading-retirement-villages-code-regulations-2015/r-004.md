### 4. Terms used and boxed and shaded paragraphs in the code of practice
(1) Except where the contrary intention appears, words and expressions used in the Code of Fair Practice for Retirement Villages 2015 have the same meanings as in the Retirement Villages Act 1992.
(2) Boxed and shaded paragraphs in the Code of Fair Practice for Retirement Villages 2015 are not part of the Code and are included only to assist readers of the Code.
