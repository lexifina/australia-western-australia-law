### 18. Code Registrar and conferral of functions
(1) The Code Registrar for the purposes of the Gas Pipelines Access (Western Australia) Law is the person appointed to or acting in the position of Code Registrar under the Gas Pipelines Access (South Australia) Act 1997 of South Australia.
(2) The Code Registrar —
(a) has the functions conferred or expressed to be conferred on the Code Registrar under the Gas Pipelines Access (Western Australia) Law or under the National Gas Agreement; and
(b) any other functions conferred on the Code Registrar by unanimous resolution of the relevant Ministers of the scheme participants.
(3) In addition to subsection (2), the Code Registrar has power to do all things necessary or convenient to be done in connection with the performance of the functions referred to in that subsection.
(4) The Code Registrar may delegate to any person any of the functions conferred on the Code Registrar by this section, other than this power of delegation.
