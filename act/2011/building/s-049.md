### 49. Application for replacement occupancy permit for permanent change of building’s use, classification
A person may apply for an occupancy permit to replace the current occupancy permit for an existing building if the person proposes either or both of the following —
(a) that the building is to be used, on a permanent basis, in a way that is different from the use authorised by the current occupancy permit;
(b) that the building’s classification is to be different from that set out in the current occupancy permit.
