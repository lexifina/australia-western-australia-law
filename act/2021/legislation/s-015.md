## Division 2 — Official versions
### 15. Official electronic versions
An electronic version of a law is an official version if —
(a) it is accessed at, or downloaded from, the WA legislation website in a prescribed format; and
(b) either —
(i) it indicates, in a prescribed way, that it is an official version; or
(ii) the website indicates, in a prescribed way, that such a version is an official version.
