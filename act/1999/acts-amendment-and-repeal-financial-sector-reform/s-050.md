## Subdivision 2 — APRA’s and ASIC’s functions under Codes
### 50. Enforcement powers
(1) In this section —
Code means the AFIC Code, Financial Institutions Code or Friendly Societies Code.
(2) Either relevant Commonwealth body has the same enforcement powers relating to anything done or omitted to be done under a Code before the transfer date as AFIC or WAFIA had immediately before that date.
(3) For the purposes of subsection (2), a Code applies with all necessary changes.
