### 17. Betting operator liable to pay betting tax
(1) In this section —
previous return period, in relation to another return period, means a return period that occurs before, and in the same assessment period as, the other return period.
(2) A betting operator is liable to pay betting tax for a return period if —
(a) the total of the taxable betting revenue of the betting operator for the return period and any previous return period exceeds the threshold amount; and
(b) the amount worked out under subsection (3) is more than zero.
