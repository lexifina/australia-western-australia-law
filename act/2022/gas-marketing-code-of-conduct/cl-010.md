## Division 4 — Miscellaneous
### 10. Compliance with code
(1) A gas marketing agent who contravenes a provision of this code commits an offence.
Penalty for this subclause:
(a)for an individual, $5 000;
(b)for a body corporate, $20 000.
(2) If a gas marketing agent contravenes a provision of this code while acting on behalf of a retailer, the retailer commits an offence.
Penalty for this subclause:
(a)for an individual, $5 000;
(b)for a body corporate, $20 000.
(3) It is a defence to a prosecution for an offence under subclause (2) if the retailer proves that the retailer used reasonable endeavours to ensure that the gas marketing agent complied with this code.
