## Division 2 — Refund mark and barcodes
[Heading inserted: SL 2026/43 r. 10.]
### 3F. Beverage product class
In this Division, 2 or more beverage products belong to the same beverage product class if the beverage products all consist of the same particular beverage packaged in a container of the same particular type.
