### 60. Examination continues to be prescribed for Class 3 security consultant’s licence and Class 3 security installer’s licence
(1) This regulation applies if, in the period beginning on 1 June 2025 and ending on 31 May 2026, a person passed an examination that was prescribed by regulation 17(1).
(2) The examination continues to be prescribed for the purposes of section 47(1)(f)(ii), but only —
(a) in relation to an application made by the person for a Class 3 security consultant’s licence or a Class 3 security installer’s licence; and
(b) until the day that is 1 year after the day on which the person passed the examination.
(3) The examination continues to be prescribed for the purposes of section 52(1)(g)(ii), but only in relation to an application made by the person for a Class 3 security consultant’s licence or a Class 3 security installer’s licence.
[Regulation 60 inserted: SL 2026/89 r. 6.]
