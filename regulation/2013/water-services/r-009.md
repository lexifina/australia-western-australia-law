### 9. Codes of practice and code of conduct: publication and notification
(1) For the purposes of section 26(10) of the Act, the Minister must, for each code of practice, publish it on the Department’s website, and keep it up-to-date.
(2) The Minister must, as soon as practicable after making or amending a code of practice, notify each licensee to whom the code applies or will apply of —
(a) the making or amendment of the code; and
(b) the website on which the code is published.
(3) The Minister must, as soon as practicable after revoking a code of practice notify each licensee to whom the code applied.
(4) For the purposes of section 27(6) of the Act, the Authority must publish the code of conduct on the Authority’s website, and keep it up-to-date.
(5) The Authority must, as soon as practicable after making, amending or replacing the code of conduct, notify each licensee to whom the code applies or will apply, of —
(a) the making, amending or replacing of the code; and
(b) the website on which the code is published.
