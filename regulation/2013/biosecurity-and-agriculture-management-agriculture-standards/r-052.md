### 52. Repeals
The following subsidiary legislation is repealed:
(a) Agricultural Produce (Chemical Residues) Regulations 1985;
(b) Agricultural Products (Citrus Fruits) Order 2008;
(c) Agricultural Products (General) Regulations 1983;
(d) Agricultural Products (Table Grapes) Order 2001;
(e) Agricultural Products (Table Grapes) Order 2012;
(f) Citrus Fruits Grading Code 2008;
(g) Fertilizers Regulations 1978;
(h) Table Grape Grading Code 2001.
