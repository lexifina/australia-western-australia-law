### 48. Revocation of interim control order halts proceedings for control order
(1) If an interim control order made without notice to the person to whom it relates is revoked under section 47 —
(a) the application for the interim control order ceases to be treated under section 40(1)(a) as an application for a control order confirming the interim control order; and
(b) the proceedings for a control order in relation to that person are discontinued.
(2) Subsection (1) does not prevent the Commissioner of Police from making another application for an interim control order, or an application for a control order, in relation to the same person.
