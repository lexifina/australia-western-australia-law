### 5. Material that is, and is not, part of Code
(1) The heading to a Part, Division or Subdivision into which this Code is divided is part of this Code.
(2) A Schedule to this Code is part of this Code.
(3) A heading to a section of this Code is not part of this Code.
(4) A footnote to this Code or to a provision of this Code, and an endnote to this Code, are not part of this Code.
