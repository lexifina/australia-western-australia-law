### 4. Material that is, and is not, part of this Code
(1) The heading to a Part, Division or Subdivision into which this Code is divided is part of this Code.
(2) A Schedule to this Code is part of this Code.
(3) Punctuation in this Code is part of this Code.
(4) A heading to a section or subsection of this Code does not form part of this Code.
(5) Notes included in this Code (including footnotes and endnotes) do not form part of this Code.
