### 19. Security officers to be employed by security agent
(1) A person who is licensed as a —
(a) security officer;
(b) security consultant; or
(c) security installer,
must not act as such unless he or she does so as an employee of a security agent and that security agent is specified in the person’s licence under section 59.
Penalty: see section 88.
(2) Subsection (1) does not apply to a licensed security agent who holds the relevant licence referred to in section 16, 17 or 18.
(3) Where a security agent’s licence is held by a natural person on behalf of a partnership or a body corporate, references in subsection (1) to a security agent include references to the partnership or the body corporate.
