### 36B. Transitional provision relating to the Railways (Access) Amendment Code 2023
(1) This section applies to a dispute to which this Division applies if, before amendment day, the dispute has been referred to arbitration.
(2) If this section applies to a dispute, this Division continues to apply to and in relation to that dispute as if the amendments made by the Railways (Access) Amendment Code 2023 sections 18 to 29 had not been made.
[Section 36B inserted: SL 2023/207 s. 30.]
